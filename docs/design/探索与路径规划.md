# 探索与路径规划

> 状态：**未定**。这是本题的**核心算法**，也是拉开差距的地方。
> 前提：迷宫 = 以入口为根的**树形结构**，现场公布，不能预输入。

---

## 1. 问题本质

题目说"不限定 DFS/BFS 或其他算法，不按算法名称评分"——翻译过来是：
**别背算法名字，解决真实问题。**

真实问题是：

> 在未知树形迷宫中，以最小化 `总时间 + 漏取罚时` 为目标，
> 决定每一步：往哪走、要不要继续深入、什么时候掉头回出口。

这是一个**在线决策 + 最优停止**问题，不是单纯的图遍历。

---

## 2. 为什么标准 DFS 不够

- DFS 会把整棵树走完 → 时间最长
- 纯贪心（就近捡）→ 可能漏掉深处高价值方块，吃重罚时
- 关键：**返回出口的时间也是成本**，走得越深，回程越贵

---

## 3. 收益模型（待建立）

对每个未探索分支，估计：

```
净收益 = Σ(该分支期望方块数 × 对应颜色罚时价值)
       − 往返该分支的移动时间
       − 拾取耗时
       − 风险成本（卡死/误判的期望损失）
```

- 罚时系数**现场才给** → 模型必须**参数化**，现场代入，不改代码
- 深度越深 → 往返成本越高，但题目说"深度不同，颜色不同，罚时不同"，
  暗示**深处方块价值更高**。需要在现场拿到规则后立刻算平衡点

---

## 4. 必须处理的现实问题

| 问题 | 说明 |
|---|---|
| 死路识别 | 进入死路要能识别并折返，不能卡死 |
| 已探索区域记忆 | 树形拓扑图：节点 + 边 + 是否已探索 + 是否已收集 |
| 回程路径 | 树上任意节点回根，直接走父指针，不需要搜索 |
| 兜底策略 | 时间超阈值 / 电量 / 卡死 → 立刻回出口，保住"有效完成" |
| 地图损毁规避 | 宁可慢，不可撞（撞了本轮 0 分） |

> **最重要的一条**：任何情况下都要保住"有效到达出口"。
> 一个方块都没捡但安全返回 = 时间分；卡死在场上 = 0。
