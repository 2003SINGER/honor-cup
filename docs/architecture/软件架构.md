## 1. 模块划分（与方案解耦）

| 模块 | 职责 | 输入 | 输出 | 目录 |
|---|---|---|---|---|
| `perception` | 循迹偏移、路口检测、方块识别 | 图像 / 雷达 / IMU | 偏移误差、路口类型、方块位姿与颜色 | `software/src/` |
| `mapping` | 树形拓扑图维护 | 路口检测结果 + 里程计 | 当前节点、分支、已探索标记 | `software/src/` |
| `planner` | 决策下一目标、回程、兜底 | 拓扑图 + 收益模型参数 | 下一个节点/动作序列 | `software/src/` |
| `control` | 运动执行、循迹 PID、避障 | 目标方向与偏移 | 底盘速度指令 | `software/src/` |
| `manipulation` | 拾取/携带机构控制 | 拾取触发 | 机构动作 | `software/src/` |
| `sim` | 迷宫仿真与策略离线验证 | 地图 + 策略 | 时间/收集数指标 | `software/sim/` |
| `tools` | 标定、录包、回放 | — | — | `software/tools/` |

## 2. 设计约束

1. **罚时系数与地图现场公布** → 收益模型参数必须**外部可配置**（配置文件/启动参数），
   **禁止硬编码**在 planner 里
2. **模块间只通过明确话题/接口通信**，便于单独替换与调试
3. **每个模块可独立运行测试**（不依赖实车）：`sim` 提供仿真数据源
4. **必须有 watchdog**：卡死/超时 → 强制回出口

---

## 3. 状态机（建议）

```
INIT → 等待开始信号
  ↓
EXPLORE（沿通道循迹 + 路口检测 + 建图 + 识别方块）
  ↓（遇方块）
COLLECT（拾取）
  ↓
DECIDE（根据收益模型：继续深入 / 折返换分支 / 回出口）
  ↓
RETURN（沿父指针回出口）
  ↓
DONE（进入出口判定区，停表）
```
任何状态异常 → `RECOVER`（原地恢复/后退重试）→ 失败则转 `RETURN`。
