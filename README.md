> **迷宫现场公布、罚时规则现场公布。**
> 因此系统必须是"在线自主"的：现场感知 → 增量建树 → 动态决策。

## 技术路线（倾向，未定稿）

**不要上 SLAM。** 题目已把连续空间问题降维成离散图搜索：树形迷宫 + 7×7 网格 + 中央黑引导线。

```
底置8路灰度 → 高速循迹 + 路口检测
顶部 RGB-D  → 提前看方块 + 认四色 + 测距
双雷达      → 看墙 / 判死路 / 剪枝 / 安全兜底
算法        → 在线 DFS + 剪枝 + 带罚时参数的收益模型
```

基线（先跑通，再优化六周）：
`巡黑线 → 检测路口 → 建树/压栈 → DFS → 认色块 → 收集 → 回退/继续 → 出出口`

难度分层：**做出来简单 · 稳定跑完中等 · 跑得快有点难 · 进前几主要拼调试和策略。**
工作量：`算法/ROS/电控 60% · 视觉 20% · 调参联调 15% · 机械 5~20%`。
