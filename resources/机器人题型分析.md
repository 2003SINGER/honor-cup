};

while (!finished) {

    }
}

你上面说的一个阵列灰度，那么如何区分T和十？

---

# chatgpt response

单独一排横向灰度阵列，**在“刚压到路口”的那个瞬间，其实分不出 T 和十字**。你这个问题抓得很准。

因为假设车沿竖线往前走：

```text
T：
   ←────→
      ↑
      车

十：
      ↑
   ←──┼──→
      ↑
      车
```

当横向 8 路阵列刚压到那条横线时，两种情况看到的都可能是：

```text
11111111
```

也就是一整排都黑。此时你只知道“这里有横向分支”，不知道前面那条纵向线还在不在。

最简单的区分方法不是加复杂视觉，而是**再往前蹭几厘米**。

比如：

```text
第一阶段：发现整排变黑
        ↓
确认到达路口

第二阶段：继续前进 3~5 cm
        ↓
看中间传感器
```

如果是十字：

```text
过了横线以后：

00011000
   ↑
中间纵线仍然存在
```

如果是 T：

```text
过了横线以后：

00000000
```

那说明正前方没有继续的线，就是一个 `左 + 右` 的 T 型路口。

所以实际状态机可以很简单：

```cpp
if (wide_black_detected()) {
    slow_down();
    move_forward_a_little();

    bool forward = center_sensor_sees_line();

    // 再结合刚才横线左右延伸情况
    if (left && right && forward)
        junction = CROSS;
    else if (left && right && !forward)
        junction = T;
}
```

而且其他情况也一样：

```text
左岔：
────┐
    ↑车

右岔：
┌────
↑车
```

你可以在“压到横向分支时”判断左右哪边出现黑色，再在**越过路口一点以后**判断正前方是否还有线。

所以一排 8 路灰度实际得到的不是“拍一张照片就判断路口”，而是利用一个很短的**时间序列**：

**进入路口前 → 压住路口 → 越过路口后**

三个时刻组合判断。

更狠一点的话，还可以装**前后两排灰度阵列**：

```text
       车头
   ○○○○○○○○   前排
       |
   ○○○○○○○○   后排
```

这样前排已经越过横线、后排还压着横线时，就能非常快地判断十字/T，而且不用刻意停车探一下。

不过对你们这题，我觉得**一排 8 路 + 向前探一点**完全够了。因为每个格子 40 cm，路口几何非常规整。真正需要调的是“探多少厘米最稳”，而不是算法本身。

所以结论就是：

**一排阵列能识别“到了路口”，但不能在单个瞬间区分 T 和十；通过前进几厘米后的中心线是否继续，就能区分。**
