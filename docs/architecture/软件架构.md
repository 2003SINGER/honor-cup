# 软件架构（2026-09-26）

现行设计真相是 [`docs/design/算法规范.md`](../design/算法规范.md)。本文件只给代码
分层与运行边界；旧的“循迹偏移→路口→收益模型”架构已存档在
[`docs/decisions/2026-09-26-旧软件架构-巡线路口状态机.md`](../decisions/2026-09-26-旧软件架构-巡线路口状态机.md)。

## 1. 规划与物理状态分层

```text
实际位姿 / 传感数据
  → Observation Adapter（只交付可信的边与方块观察）
  → EdgeMap + TreeInference / BlockMap
  → CellMark + 局部 BranchState / TaskPruning
  → TopologicalCursor(prev, cell) + ActionHorizon
  → MotionPlanner 固定模板
  → SpeedProfile + TrajectoryReference
  → PositionController（body Twist，独立 yaw hold）
  → /cmd_vel → 官方下位速度环 → 电机/编码器 → 实际位姿
```

物理位姿只有一个 owner：Tier A 语义模拟由 `MotionExecutor` 持有；单独的控制
门槛由 `IdealPlant` 或 `LowerLoopPlant` 持有。离散规划不得用连续 Pose 反推
`prev_cell` 或格线归属。地图、树推理与任务剪枝不向运动编译器注入任意连接线。

## 2. 活动代码的真实位置

| 层 | 代码 | 职责 |
|---|---|---|
| 物理地图 | `software/ros2/m3pro_nav/m3pro_nav/edge_map.py`、`tree_inference.py` | 墙、开放边、已走边分离；树公理推断 |
| 任务知识 | `block_map.py`、`task_pruning.py` | 方块正负信息与可撤销空死枝证明 |
| 图决策 | `stream_nav.py`、`action_horizon.py` | 局部 DFS、计划 overlay、拓扑游标与有限动作链 |
| 固定几何 | `motion_primitive.py`、`motion_planner.py` | 轴向直线、R=0.2 四分之一圆、折返和 STOP |
| Tier A 执行 | `motion_executor.py`、`software/sim/runtime_v2.py` | 理想几何积分、事件与语义传感回归 |
| 运动控制 | `speed_profile.py`、`trajectory_reference.py`、`position_controller.py`、`control_chain.py`、`plant.py` | 速度规划、参考、外环、下位环模型 |
| 车端入口 | `driver_probe.py`、`software/ros2/m3pro_nav/launch/m3pro.launch.py` | 默认只读的官方话题/CSV 接入探针 |

上述单文件名除显式前缀外，都位于 `software/ros2/m3pro_nav/m3pro_nav/`。
`car/` 是官方车端工作空间，保持独立；本仓库的算法层不修改其固件或驱动。

Action Horizon 在每次续编时传入前一次的虚拟 DFS overlay；运行时以队尾
`STOP` 的位姿和拓扑游标编后缀，再由执行器校验接缝。正在执行的基元不被
重编。若接缝无法安全消除等待，后缀接在该 `STOP` 之后；传感器在格线上
用当前等待动作的格子消歧，不使用远处队尾游标。

## 3. 当前验证边界

- Tier A：固定模板分支曾通过 51 项确定性契约与 fullinfo、blocks 各
  1000 seed；当前滚动续编分支通过 95 项确定性测试与两种模式各 10 seed。
  详见 [`TODO.md`](../../TODO.md)。这证明模拟中的拓扑/任务/固定几何
  接口，不证明雷达可信度、定位或实车运动。
- 控制层：五项固定机动用 10 ms 下位环模拟跑通，电机 PWM→轮速响应仍是
  `UNCALIBRATED`；源码与指标见
  [`运动控制链与下位机审计.md`](运动控制链与下位机审计.md)。
- 车端：只读/小阶跃 ROS 探针已写，尚未在车端执行。已观察到的真实话题与
  启动环境以 [`docs/车端实测记录.md`](../车端实测记录.md) 为准。

## 4. 后续接入顺序

先核对实车话题和当前已烧录固件，再采集小幅命令与 encoder/odom/IMU 的
响应数据；据此标定下位模型与位置环。之后接真实 Observation Adapter：
已确认墙参与位姿校正，新观察只在校正后更新地图，不允许本帧新墙自证。
最后用信息视界距离控制速度，在真实可观测范围内验收，而不是调整
随机迷宫参数来提高模拟成绩。
