| 黄色方块 | 待定 | 2 | ⬜ 未采购 |
| 蓝色方块 | 待定 | 2 | ⬜ 未采购 |

**方块硬要求**：不得布置电路、不得与车通信、赛前接受核验。

**⚠️ 采购时必须按"机械臂 + 磁吸 两条路都留着"设计**（详见 `docs/design/机械与收集机构.md` 第 2.4 节）：

| 设计要求 | 为谁服务 |
|---|---|
| **内嵌铁片 / 金属底片** | 磁吸（后期可能切换的方案） |
| 外表面平整、有夹持面 | 机械臂夹爪 |
| 尺寸统一、便于堆叠 | 携带容器 / 磁吸阵列 |
| 颜色饱和度高、四色 HSV 分离度大 | 视觉识别（官方 `color_recognize` 用 HSV 阈值） |
| 不含任何电路 | 硬性规则 |

> **理由：方块是一次性决策**（自备 + 核验 + 要早买），而机械臂/磁吸是**可以后期切换**的执行方式。
> 不能等"试完机械臂再决定方块怎么做" —— 那时已经来不及重做方块了。
> 内嵌铁片**不算电路**，规则允许（只禁"方块上布置电路"），建议备料时留样品以便核验时说明。
