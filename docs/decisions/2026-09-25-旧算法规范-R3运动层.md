# 算法规范 —— 前视格状态流式确认探索 (Predictive Cell-State Streaming Exploration)

> 本文档是**现行算法的唯一规范**。历史方案、被否定方案、历史数字见 `docs/decisions/`。
> 代码与本规范冲突时：先列冲突，**不许偷偷改规范迁就代码**。

## 1. 设计目标与核心 invariant

**一句话**：系统通过雷达、已有墙地图和树结构约束，持续把车辆前方的 UNKNOWN cells
转化为 COMPLETE CellMarks；COMPLETE 区域立即按已知路径执行；DFS 只负责 BRANCH
的分支顺序；车辆速度由 Known Horizon 与运动 commit deadline 动态决定。

**核心 invariant（系统宪法）**：

> 车辆越过某个运动 primitive 的 commit line 之前，执行该 primitive 所依赖的
> CellMark 必须 COMPLETE。

- 来得及确认 → 未知路段立即升级为已知路径，直接执行 Straight/Cut/Turn。
- 来不及 → 按刹车距离降速 → 进入 CREEP_OBSERVE → 最晚在安全停止线前完成判断 →
  仍不能完成则 STOP，**禁止猜**。
- **绝对禁止**：已过入弯点才确认转向 → 硬启动 cut。（这是历史 far_cut 崩坏的根因）

## 2. EdgeMap / TraversalMap —— 两件事彻底解耦

**墙的几何真相**与**车走过没有**是两个独立维度：

| 层 | 状态 | owner |
|---|---|---|
| `EdgeMap` | UNKNOWN / WALL / OPEN (+ provenance, confidence) | EdgeBelief |
| `TraversalMap` | WALKED / NOT_WALKED | crossed-edge 事件 (R3 起) / 离散簿记 (现行) |

一条合法边可以是 OPEN+NOT_WALKED（雷达/树推理提前得知）或 OPEN+WALKED（真开过）。
**禁止**再用 `seen` 这种混合状态。

## 3. EdgeBelief 与来源

- signed score：墙证据 +1 / 开口证据 −1（仅过入射角门限的观测计入；**每帧都更新，
  已确认状态也更新**——这是可撤销的前提）。
- 状态机（确定性，必须可单测）：
  - UNKNOWN: score ≥ +T_CONFIRM → WALL；score ≤ −T_CONFIRM → OPEN
  - WALL: 只有 score ≤ −T_FLIP → OPEN（中间保持 WALL）
  - OPEN: 只有 score ≥ +T_FLIP → WALL（中间保持 OPEN）
  - T_CONFIRM=2, T_FLIP=4。**T_FLIP 必须真实参与翻转条件**（历史 bug：通用分支使迟滞失效）。
- 来源 provenance：SENSOR / WALKED / BOUNDARY / TREE_INFERENCE。
- walked 是物理事实：传感器与 walked 矛盾 → 记录 contradiction（诊断信号：定位/关联/
  时间同步出错），**不修改 walked**。
- 观测置信（入射角模型）：err = max(σ, D·δα/cos²α)，α=射线与墙法线夹角，D=dist·cosα。
- canonical key：同一物理边全系统只有一份 belief。

## 4. TreeInference（树结构公理闭包）

独立模块，只读 EdgeMap，不看雷达距离/速度/heading/DFS 顺序。

- **规则 A（成环必墙）**：UNKNOWN 边两端已在 confirmed-OPEN 图中连通 → 该边 = WALL。
- 规则 B（桥必 OPEN）/ C（分量唯一出口）/ D（边数 |E|=|V|−1）：
  **仅在赛题正式保证所有格点构成同一棵连通树时启用**（feature flag `assume_tree`）。
  禁止为剪枝强度引入未经题面保证的规则。

## 5. CellMark / CellClassifier

CellMark 是核心领域对象——**格子的状态包含"怎么走"的信息**：

```
CellMark:
  N/E/S/W: UNKNOWN/WALL/OPEN
  complete: 四边是否全部确定
  degree: OPEN 数
  kind: DEAD(degree=1) / WAY(=2) / BRANCH(≥3)
  transition: entry_side -> unique_exit_side   (仅非岔路)
```

CellClassifier 只关心四边是否全部确定，**不关心事实来自雷达还是树推理**。

## 6. DFSExplorer —— DFS 职责缩小到只剩岔路调度

- 只在 BRANCH 节点决策：push branch、按 order 选未探 child、子树探完回 branch 选下一个、
  全部完成 pop。
- DEAD/WAY 的运动完全由 CellMark.transition 决定，**不进 DFS 决策**。
- `nearest_frontier` 作为**探索策略**被废除（它把 DFS 变成了近邻探索，破坏深度优先的
  空间局部性）。BFS/最短路只作为 **RoutePlanner**（已决定目标后怎么去；树中
  parent 链即可）。
- ExplorationPolicy ≠ RoutePlanner。

## 7. KnownHorizonPlanner

从当前位置沿意图链展开连续 CellMark，直到第一个 INCOMPLETE：

```
[A COMPLETE straight][B COMPLETE straight][C COMPLETE left][D INCOMPLETE]
                        └────── Known Horizon ──────┘      ↑ 未知边界
```

输出：未来 cells、future motion intents、first incomplete 决策点、到 commit/减速线距离。
速度规划反推：`v_max ≤ √(2·a_dec·d_remain)`；已知 straight 全速；已知 cut 须在
commit point 前降到 v_cut。**速度不取决于"探索/已知"模式，而取决于最坏情况刹车距离。**

## 8. MoveIntent / MotionPlanner / MotionExecutor

- StreamNav 只输出 **MoveIntent**（next_edge / preferred_continuation / 远格停车需求），
  **不输出** end_o/v_end/turn_here 等执行细节。
- MotionPlanner 依据当前**真实运动进度**选 primitive：未过 cut entry → CUT90；
  已过 commit point → STOP_AT_NODE + SPIN90；信息不足 → CREEP_OBSERVE；速度过高 → BRAKE。
- MotionExecutor 拥有**唯一权威 Pose**；SensorSim、碰撞、可视化全部读同一个 Pose。
- cut 完成最多产生 A→B 一个 crossed-edge；B→C 须连续轨迹真实跨越后才产生。
- primitive 契约：start_pose / preconditions / commit_point / cancel_deadline /
  progress / done_condition / events。（R3 实现，本规范先冻结契约）

## 9. CREEP_OBSERVE（正式 primitive，不是 wait 补丁）

字段：target cell、required unknown edges、max crawl distance、latest safe stop line。
完成条件：CellMark.complete。失败：到 latest stop line 仍 incomplete → STOP。
**禁止**：无限 wait / 无限 crawl / 因看不清标记 unreachable。

## 10. 定位与扫描吸附（防自证循环）

顺序固定：odom+IMU 预测 pose → **只用已确认的墙**做 data association（单一匹配且
residual 过 gate 才修 map→odom）→ 用校正后 pose 发现**新**墙。
禁止拿刚猜出来的新墙立即反证自己的 pose。

## 11. Sim 分级

- **Tier A SemanticSim**：输入即 EdgeObservation，验证认知算法（现 World 属于此级）。
  不验证 scan 关联/TF/定位误差。
- **Tier B SensorSim**：输入只允许 raw scan/odom/IMU/camera，走 EdgeObserver（R 阶段后）。
- 性能数字必须带级别标注；failures>0 → 该数字 INVALID。

## 12. 状态 ownership 表（唯一答案，出现两个答案即 FAIL）

| 事实 | 唯一 owner |
|---|---|
| 墙/开口真相 | EdgeMap (EdgeBelief 写入) |
| walked | TraversalMap (crossed-edge 事件) |
| 格子分类 | CellClassifier (CellMark) |
| 探索顺序 | DFSExplorer |
| 已知范围/速度 | KnownHorizonPlanner |
| 运动决策 | MotionPlanner (R3) |
| 权威位姿 | MotionExecutor (R3) |
| 定位修正 | GridLocalizer (P1) |

## 13. 探索完成条件

不是"所有格 visited"，也不是"seen 全 walked"，而是：**目标地图所需的所有 EdgeFact
已确定**（含树推理确定的、从未进入的区域）。

## 14. 验收 Gate

G0 Core deterministic pytest（topology/evidence/dfs/horizon 全绿）
→ G1 SemanticSim 1000 seeds 0 abort/0 越界/0 fallback
→ G2 SensorSim（无 truth cell/dir）
→ G3 rosbag replay → G4 台架 → G5 一格 → G6 小迷宫 → G7 全程。
G5 之前禁止优化 cut/速度/剪枝收益。
