## 0. 总纲（最高 invariant，任何设计违反即判错）

> 机器人并不等待整张迷宫成为"绝对已知"后才高速运动。
>
> 雷达、里程计、IMU 和已有确认墙共同维护连续位姿；随着机器人运动，
> 雷达可置信范围连续扫过未知地图，可信观测立即离散为格子边信息。
> 只要未来格的信息已足以确定下一出口，该格就立即成为可执行的
> "局部已知路径"，机器人直接按固定麦轮轨迹模板通过。
>
> 长期确认地图主要用于回溯、高速已知路径、树迷宫剪枝和定位校正，
> 而不是正常前进的许可条件。

四条最高约束（由 2026-09-25 对话定案）：

1. 当前可信信息立即可用于运动，不等长期地图确认。
2. Cell 状态必须直接导出下一出口/动作（格子的状态里就包含"怎么走"）。
3. 麦轮 travel direction 与 body yaw 解耦。
4. 长期地图主要服务于回头、剪枝、定位，不是前进许可。

一句话算法：

> **墙负责把格子变成离散指令；格子负责告诉车下一条边；运动层只负责执行固定模板。**

## 1. 两类"已知"——本项目最核心的概念区分

### 1.1 Rolling Trusted Knowledge（滚动可信知识）

- 当前连续 Pose 下，由雷达几何 + 误差模型允许可信确认的信息
- **临时/实时、连续空间、各向异性**（正前可信远，侧向掠射可信近）
- 一旦足以确定未来格动作，**立即用于运动**
- 车每前进 1cm，可信遮罩就跟着前进 1cm

### 1.2 Persistent Confirmed Map（持久确认地图）

- 多帧确认 + 真实走过 + 吸附校准后的长期拓扑事实
- 用途：**回溯、已知路径高速运行、树结构剪枝、位姿校准、全局路径规划**
- 绝对禁止当作正常前进的许可条件

### 1.3 认知分级

```text
OBSERVED NOW   当前这一帧可信 → 可用于马上做动作
CONFIRMED      多帧/几何一致   → 写入长期地图
HARD           真实走过/边界/强结构推理 → 近乎不可撤销
```

运动可以吃前两级中足够安全的局部信息；剪枝主要吃 CONFIRMED/HARD；
定位校正尽量只用已确认的墙。

历史上所有 wait / creep / 进格再决策 / 复杂 commit，全部源于把
1.1 偷换成 1.2（"必须绝对已知才能走"）。此错误已定案废除。

## 2. 完整数据流

```text
Wheel Odom + IMU
        ↓
Pose Prediction（预测连续位姿）
        ↓
Confirmed-Wall Correction ←—— 已确认墙（只有 CONFIRMED 墙可参与）
        ↓
Corrected Continuous Pose
        ↓
Lidar Trusted Mask / Edge Association（连续可信遮罩 + 边离散归属）
        ↓
EdgeMap（N/E/S/W = UNKNOWN/WALL/OPEN，带 provenance）
        ↓
TreeInference（树公理闭包：成环必墙，纯 base 重算、可撤销）
        ↓
CellMark（degree/kind：DEAD=1口 / WAY=2口 / BRANCH≥3口）
        ↓
CellAction(entry_side → exit_side)   ←—— 格子状态直接导出怎么走
        ↓
Action Horizon（从当前位置向前逐格读动作，遇 UNKNOWN 停）
        ↓
Fixed Mecanum Trajectory Templates（STRAIGHT / 左右 1/4 圆弧 / REVERSE / STOP）
        ↓
world-frame (vx, vy) + wz(yaw hold)
        ↓
body-frame mecanum 逆解 → 四轮目标速度 → 轮速 PID
```

旁路（长期地图的三个服务对象）：

```text
Persistent Confirmed Map
    ├→ Tree Pruning（树结构剪枝）
    ├→ Return / Route Planning（回头高速跑、收齐后奔出口：唯一允许 BFS/最短路处）
    └→ Localization Reference（定位校正参考墙）
```

## 3. 运动学前提：车身方向 ≠ 行驶方向

麦轮车的根本自由度：

```text
body_yaw          车身朝向 —— 姿态保持环负责，正常导航全程固定
travel_direction  平移速度矢量方向 —— 路径跟踪负责，随时变
```

正常迷宫运行中 `body_yaw_ref = 启动时固定方向`，恒定。
麦轮改变的是 `vx_world / vy_world`，不是车头方向。

**禁止出现**（正常导航路径中）：

```text
SPIN90 / TURN180 / recenter-before-spin
yaw0=TH[d]、yaw1=TH[next]（yaw 跟随行驶方向）
往东走 → yaw 转东
nearest_axis(yaw) 作为拓扑行驶方向
```

yaw 只由独立闭环控制：`wz = yaw_hold_controller(yaw_ref − yaw)`。
路径跟踪与姿态保持二者独立，最后在麦轮逆解汇合：

```text
(vx_world, vy_world) → 按 body_yaw 转车体系 → (vx_body, vy_body, wz)
→ 四轮目标速度 → 轮速 PID
```

## 4. 固定运动模板（整个比赛只用这一套）

格长 `C = 0.4m`，转弯统一 `R = C/2 = 0.2m` 四分之一圆弧。

**禁止**根据弯道类型/围墙几何/seed/左右弯单独调整轨迹。
如真实车体证明 R=0.2 净空不足，只允许统一改一个全局模板参数。

所有合法动作由 `(entry_side, exit_side)` 查模板：

| entry→exit | 模板 | 几何 |
|---|---|---|
| exit = 对边 | STRAIGHT | 入口边中点 → 出口边中点 |
| exit 与 entry 相邻 | LEFT/RIGHT_ARC | R=0.2 四分之一圆，圆心=内角点，与前后直线天然相切 |
| exit = entry | REVERSE | 沿原轨迹反向平移（死路折返），**不是 TURN180** |
| CellMark 未完成 | STOP | v=0 原地等扫描（唯一合法等待行为） |

速度模板：

- 弧内 |v| = v_arc 恒定；直线段进入弧前减速至 v_arc，出弧后重新加速
- 要求：速度大小连续、速度方向连续、四电机目标速度在模板接缝无跳变
- DEAD 格若需抓方块：入口 → 格中心（停车抓取）→ 原路反向退出，yaw 仍不变

模板接缝的几何必然：每个格子动作从入口边中点到出口边中点，
**接缝恰好落在格线上**。事件检测必须把"恰在格线上、下一帧离线"
判为真实跨越（见 §9 / Gate K）。

## 5. CellMark / CellAction：格子只负责告诉车"下一边走哪里"

```text
CellMark: N/E/S/W = UNKNOWN/WALL/OPEN + degree + kind
OPEN=1 → DEAD    OPEN=2 → WAY    OPEN≥3 → BRANCH
```

入口边天然已知 OPEN（车能开过来就证明这条边通）。
所以即将进入 B 格时，真正要确认的一般只是另外三条边。

统一接口：

```python
resolve_exit(cell, entry_side) -> exit_side | UNKNOWN
template(entry_side, exit_side) -> 固定模板
```

- **WAY**：纯查表。opens={S,N} 则 entry=S→exit=N；无任何探索状态。
- **DEAD**：exit = entry_side → REVERSE，不做搜索。
- **BRANCH**：格子自己保存下一出口（§6）。

运动层完全不关心 DFS。

## 6. BRANCH：格子局部状态机（无全局 DFS stack）

```text
BranchState:
    parent_side          首次真实进入的边，冻结永不变
    ordered_children     按 L/F/R 等规则排序
    completed_children
    next_exit
```

- 第一次真实进入（`EnteredCell(B, from=S)` 事件）→ parent_side=S 冻结，
  children 排序，next_exit = 第一个 child
- 从 child X 回来（`EnteredCell(B, from=X)`）→ 树迷宫保证 X 子树已结束：
  X → completed，next_exit = 下一个未完成 child
- children 全完成 → next_exit = parent_side → 自动向父 branch 回去

这套局部状态递归**本身就是 DFS**。树的隐式递归栈不需要显式全局 stack。

**禁止**把全局 DFS stack / backtrack_target / route_to_branch 写成每格
运动决策器。BFS/最短路只允许用于"收齐方块后回出口"等非探索任务。

### preview 规则

车未真实进入但 CellMark 已 COMPLETE 的 BRANCH：`preview_exit(B, predicted_entry)`
可纯函数预测首个 child（用于提前编模板），但 parent_side / completed_children
**必须等真实 EnteredCell 事件才写**，preview 零副作用。

## 7. 数墙分类 vs 树剪枝：两个完全不同的模块

### 7.1 Local Cell Classification（数墙定动作）

只关注目标格四条边的离散状态：

```text
已有登记 + 当前可信雷达 + 真实来向 → CellMark → CellAction
```

不需要关心附近的路走没走过。用户原话：
"数墙不仅仅是剪枝，数墙能直接定是否岔路以及向哪移动！"

### 7.2 Tree Pruning（长期地图推理）

使用持久确认图 + 树约束推断没直接看到的 UNKNOWN 边：

```text
若某 UNKNOWN 边设为 OPEN 会形成环 → 必为 WALL
```

剪枝结果可以**提前补全 CellMark**，但剪枝不是车辆正常运动的前置条件。
（例：长直道远处，左右两排格子已探索 → 远处格子按树性质左右必为墙，
不需要雷达靠近扫到。）

## 8. Trusted Mask：连续几何可信遮罩（核心感知概念）

**禁止**写成"前方看 4 格、侧边看 1 格"的离散规则。
正确定义：对每个观测独立计算

```text
trusted(observation) = f(
    continuous pose, sensor extrinsics, range,
    incidence angle, range noise, angular noise,
    grid-association residual)
```

- 估计墙位置误差 < gate → ACCEPT（吸附/更新 EdgeMap）
- 否则 → **ABSTAIN**（宁可不写，不允许猜错墙）
- 典型特性：正前方向可信较远；近侧墙可信；远处掠射侧墙可信距离短
- 侧墙沿误差模型：`err ≈ D·δφ / cos²(α)`（α = 射线与墙法线夹角），
  正对墙误差 ≈ 量程噪声（远也准）
- 遮罩随连续 Pose 连续移动；**正常前进本身让原本不可信的墙进入可信范围**

关键纠正（2026-09-25 定案）：旧模拟把"这条远侧墙暂时不能可靠吸附"
错误等同于"必须慢慢蹭近再看"，由此造出 CREEP。正确逻辑是：

> 每条墙一进入自己的可信范围就立刻吸附入图；不要等到进格以后才认识格子。
> UNKNOWN 只是"暂未成熟"，不是"停车信号"。

## 9. 定位前端：因果顺序与防自证循环

```text
odom + IMU → predicted pose
已确认墙   → pose correction（wall alignment）
corrected pose → 本帧新观测的离散归属 + 置信更新
```

**顺序禁止倒过来。**

防自证循环铁律：

> 新墙不能在同一帧先被假定为某格线、用来校正 Pose，再反过来证明自己属于该格线。

- 已 CONFIRMED 的墙：可参与当前帧 pose correction
- 新 candidate：只能在 corrected pose 下做离散归属和置信更新；
  达到确认阈值后从下一帧起才有资格成为定位参考墙

吸附规则：雷达测得墙位置投影到最近合法格线 k·C，仅当
残差 < snap_gate 且 candidate 唯一才更新 (cell, side)，否则 ABSTAIN。
每次移动不是搜索匹配，而是按坐标和移动趋势直接算最好吸附。

## 10. 速度控制：由信息视界决定，不是由"模式"决定

不存在 EXPLORE（慢）/ KNOWN（快）两个模式。只有一个：

```text
d_unknown = 沿未来路径到第一个"动作还不能确定"的位置的距离
v_max = min(v_vehicle, √(2·a_dec·(d_unknown − margin)))
```

- `d_unknown > stopping_distance(v) + margin` → 保持高速
- 可信遮罩滚动前进 → UNKNOWN→trusted→CellAction → Action Horizon 自动延伸
- 信息视界逼近安全停止距离才线性减速
- 真正到安全极限仍 UNKNOWN → STOP，原地继续扫描（**异常/边界情况，不是每格正常流程**）

正常数量级检查：10Hz 扫描 + 0.7m/s + 格长 0.4m → 一格 5~6 帧，
且雷达提前 2~3 格就开始看 → "每格必须 creep 才能认识" 本来就不成立。

## 11. WAIT 的位置（保证固定模板永远能直接套）

必须在"该格动作模板开始之前"得到 exit_side（R=0.2 圆弧从入口边中点
切出，进弧前必须知道直行还是转弯）。

因此未来格仍 UNKNOWN 时：在其**入口模板起点之前**的安全直线位置停车，
而不是先冲到格中心再决定左右。

## 13. 验收 Gate（deterministic → 随机，逐级解锁）

| Gate | 内容 | 通过标准 |
|---|---|---|
| A | CellAction 穷举：所有 COMPLETE CellMark × 4 个 entry_side | WAY→唯一另一 OPEN；DEAD→entry；BRANCH→next_exit；绝不输出 WALL/越界 |
| B | Branch 局部 DFS：固定嵌套树事件序列 | 0 global stack / 0 nearest-frontier / 每 child 恰一次 / parent_side 永不变 |
| C | 固定圆弧几何：真实车体（0.29×0.215m）× 4 entry × 左右转 swept-OBB 碰撞 | 0 collision，输出最小 clearance；R 只能全局调 |
| D | yaw 固定：STRAIGHT→ARC→STRAIGHT→ARC→REVERSE 连跑 | body_yaw_ref 全程不变（仅闭环小误差） |
| E | 速度连续：模板接缝 \|v\| 与方向连续，四轮 RPM 无不合理跃变 | 受 a_max/jerk 限制内平滑 |
| F | WAIT 可观测性实验：所有合法局部墙型 × 4 entry × 噪声，在等待位置有限帧内确认其余三边 | 全过 → CREEP 永久删除；失败 → 先改感知/安装/可信范围，不得加蠕动 |
| G | 定位因果：注入 odom/yaw drift，已确认墙降低定位误差；假墙不影响本帧校正 | 防自证成立 |
| H | 墙登记准确率：随机真值 Pose + 噪声，accepted observation 的 canonical edge 与真值一致 | wrong_wall_assignment = 0，宁可 ABSTAIN |
| I | 提前识别：长直道 A→E，CellMark(B/C/…) 提前生成，Horizon 连续读 | 不是每进一格重算 |
| J | UNKNOWN fallback：直到模板起点仍未识别 → 安全减速停在模板起点前 v=0 继续扫；COMPLETE 后下一控制周期直接装载 | 禁止 CREEP/SPIN/重搜索 |
| K | CrossedEdge：连续路径真实跨格线产生事件（含弧线 entry→exit 中点、含"格线停靠后离线"） | 0 漏 / 0 重 / 0 幻，不允许预登记 |
| L | 确定性迷宫：直道/单左弯/单右弯/S 弯/连续弯/dead end/单 branch/两层嵌套 branch | 0 collision / 0 wrong edge / 0 wrong child / 0 illegal exit / 0 spin / 0 creep |
| M | 随机 baseline：Gate L 全过后 100 full-map + 100 blocks seeds，再 1000 | 0 abort / 0 collision / 0 wrong_edges / 0 OOB |

本轮不做性能极限优化（§14），先证明最简单的算法正确。
