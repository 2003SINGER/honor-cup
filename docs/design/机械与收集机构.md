# 机械与收集机构

> 状态：**未定**。
> 硬约束：横向宽度 ≤ **21.5 cm**（任何状态），最大高度 ≤ **55 cm**（含机械臂臂长）。

---

## 1. 约束换算

| 项 | 数值 | 说明 |
|---|---|---|
| 原车宽 | 21.5 cm | **附加装置的绝对上限** |
| 原车长 | 27.5 cm | 长度方向题目未限制，但转弯时要考虑 |
| 通道宽 | 40 cm | |
| 单侧余量 | **9.25 cm** | (40 - 21.5) / 2 |
| 挡板高 | 55 cm | 高度上限 |

> 判断：**扫杆方案要特别小心**。题目虽明确允许"横跨通道的扫杆"，但宽度仍受 21.5 cm 限制 —— 意味着扫杆不能是刚性横杆，必须是**可收展**的：收纳时 ≤21.5cm，展开时可超出但……注意原文是"任何比赛状态下的最大横向宽度均不得超过原车宽"。
> **这实际上否定了展开式横扫杆。** 除非展开宽度 ≤21.5cm（那就扫不满 40cm 通道，意义有限）。
> → 该条款需与组委会确认，或放弃扫杆方案。这是目前发现的**题目内部张力**，别踩。

---

## 2. 候选收集方案

| 方案 | 原理 | 优点 | 风险 | 尺寸压力 |
|---|---|---|---|---|
| **S1 机械臂夹爪** | 视觉定位后夹取 | 精准、平台自带 | 每次拾取耗时长（8 个方块 × 抓取时间）；对定位精度要求高 | 臂长受 55cm 限，收纳姿态要设计 |
| **S2 前置收集筐/铲斗** | 车头推铲，方块被铲入筐 | **拾取极快**（不停留），结构简单 | 需要精确对准；可能推歪方块；筐占长度 | 宽 ≤21.5cm，需贴地 |
| **S3 磁吸** | 方块内嵌铁片，车底/车头电磁铁或永磁铁吸附 | 无需对准夹爪，可"路过即吸" | 方块须内嵌铁片（自备，允许）；吸附力 vs 掉落风险 | 增加高度小 |
| **S4 扫杆扫入** | 横杆把方块扫到一侧收集 | 覆盖面广 | **宽度条款存疑**（见上） | 大 |

> 倾向：**S2 或 S3，或 S2+S3 组合**（前铲 + 磁吸，路过即收）。
> 理由：成绩主项是**时间**，S1 的每次"停下→对准→夹取→放置"会吃掉大量秒数；8 个方块若各花 10 秒抓取就是 80 秒，很可能大于漏取罚时。
> **但这一切取决于罚时系数** —— 若深处方块罚时极重，则必须全捡，S1 的稳定性反而值。
> → **罚时规则出来前，机构不要定死。** 先做能同时兼容两种的底盘布局。

> 出题人自己列了"收集筐、磁吸装置、扫杆"，并说"方块也可作为整体方案的一部分协同设计"
> —— 这是在**暗示别用机械臂一个个夹**。做一个"作弊器式"的极简被动机构，
> 让车碰到方块就吞进去，把"停车→对准→伸臂→夹→收回"整段省掉。

## 2.2 关键区分：抓取机构 ≠ 携带容器

**这其实是两个独立决策，很容易混为一谈。**

| | 作用 | 候选 |
|---|---|---|
| **抓取机构** | 把方块从地上弄上车 | 机械臂夹爪 / 磁吸 / 前铲 / 扫杆 |
| **携带容器** | 把 **8 个**方块装住带到出口 | 收集筐 / 底板 / 磁吸阵列 |

**机械臂的最大短板就在第二列：它只是抓取机构，不解决携带。**

- 一次夹 1 个 → 夹完得先丢进筐里，再继续走
- **没有筐的话，就得为一个方块往返出口一次 → 8 个方块往返 8 次，时间上完全不可接受**
- 所以**机械臂方案必须配一个暂存筐**（占了空间和高度，且要高 ≤55 cm）

**磁吸的巧妙之处：它同时解决抓取和携带。**吸住即携带，不需要额外的筐。

> **推论：如果磁吸可行，它比"机械臂 + 筐"更简单。**
> 但不能默认可行，见下。

---

## 2.3 磁吸的三个前置条件（缺一个就不成立）

### ① 挡板材质 —— 最关键，必须先问

**如果迷宫挡板是铁磁性材质（铁/钢），车侧的磁铁会把车吸在墙上。**
后果是灾难性的：轻则卡死（时间无限大），重则推倒挡板 → **本轮成绩无效**。

→ **必须问科协：迷宫挡板是什么材质？** 在得到答复前不要定型磁吸方案。

### ② 磁铁位置不能挡住巡线相机

官方巡线是**顶部相机往下看黑线**（见 `docs/官方例程盘点.md`）。
如果磁铁/吸附的方块位于车底正中，**正好会遮住相机视野** → 巡线直接失效。

→ 磁吸应放在**车头前伸**或**车尾**，避开相机正下方。这个在底盘布局阶段就要定。

### ③ 永磁 vs 电磁

| | 永磁铁 | 电磁铁 |
|---|---|---|
| 供电 | 不需要 | 需要 |
| 控制 | 不需要 | 需要 |
| 吸住后能否松开 | 不能（也不需要） | 能 |
| 复杂度 | **低** | 中 |

> **判断：倾向于永磁。** 因为题目规定"方块随车到出口判定区域"即算收集成功——
> **不需要在迷宫里把方块放下**。吸住不松开反而是好事。
> 电磁铁的"可释放"能力在本题用不上，却要付供电和控制的代价。

## 2.4 战术建议：方块要现在就按"两条路都留着"设计

**时间线不匹配**：方块是**一次性决策**（要自备、要过核验、要早买），
而机械臂/磁吸是**可以后期切换**的执行方式。

→ **不能等"试完机械臂再决定方块怎么做"，那时已经来不及改方块了。**

方块设计要同时满足两条路：

| 要求 | 为谁服务 |
|---|---|
| 内嵌铁片（或金属底片） | 磁吸 |
| 外表面平整、有夹持面 | 机械臂夹爪 |
| 尺寸统一、便于堆叠 | 携带容器 / 磁吸阵列 |
| 颜色饱和度高、四色 HSV 分离度大 | 视觉识别 |
| **不含任何电路** | 硬性规则（赛前核验） |

> ⚠️ 内嵌铁片**不算电路**，规则允许（规则只禁"方块上布置电路"）。
> 但核验时要能说清楚，建议备料时保留说明或样品。

## 2.5 机械改动量（先看这个再动手）

| 改动 | 必要性 | 工作量 |
|---|---|---|
| **底置 8 路灰度阵列** | 低（官方用相机巡线，已跑通） | 见 `hardware/平台硬件.md` 4.1 |
| 抓取机构（机械臂） | 先试，零成本（官方例程现成） | 低 |
| **携带容器（筐/底板）** | **高** —— 机械臂方案的必备件 | 中（且占高度，受 55 cm 限制） |
| 磁吸阵列 | 备选，待挡板材质确认 | 低~中 |
| 其他结构改装 | 低 | — |

> **真正的难点不在机械，在高速调 PID 和路口判定。**
> **顺序建议：先跑官方机械臂例程验证到位 → 同时把方块按双方案备好 → 磁吸等挡板材质确认后再上。**

**电气接法（重要，别莽接 Jetson GPIO）**

```
8路灰度阵列
    ↓
小 MCU（Arduino Nano / STM32 / RP2040）   ← 5V 电平隔离，不动原厂固件
    ↓ USB 串口
Jetson Orin NX（ROS2 节点）
```

上位机只需两个量：`line_error`（如 −1.7 ~ +1.7）和 `junction_flag`。
详见 `hardware/平台硬件.md` 第 4 节。

> ⚠️ 有 STM32 底层控制板 ≠ 一定有空闲通用 GPIO 给你插 8 路阵列。
> **拿到车先看控制板接口，别默认能直连。**
