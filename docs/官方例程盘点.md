## 3. 与赛题直接相关的 5 个例程

### ① 巡线自动驾驶 — `1.底盘控制/6.巡线自动驾驶/`

> 官方原文："启动程序后，机器人会**锁定面前的地标线**，按空格开始后，机器人沿地面路标线行驶，
> 如果沿途出现障碍物则暂停移动同时蜂鸣器报警，直到路标线消失时停止运动"

**确认：巡线用的是奥比中光 Dabai_DCW2 深度相机做视觉巡线，不是底置灰度阵列。**

### ② 巡线清障 — `4.机械臂与三维空间夹取/15.巡线清障/` ⭐

> 官方原文："程序通过相机获取图像并且识别巡线的颜色，程序会控制小车沿着线移动，
> 期间**激光雷达会扫描路径上的障碍物**，如果遇到障碍物，就会停车；
> 如果路线上出现了机器码，那么就会调整姿态，**下爪夹取机器码**，并把它放在一边后**继续巡线前进**。"

启动命令（三条终端）：
```bash
ros2 launch M3Pro_demo camera_arm_kin.launch.py   # 机械臂解算 + 相机驱动
ros2 run   M3Pro_demo grasp_desktop               # 机械臂夹取
ros2 run   M3Pro_demo follow_line                 # 巡线清障
```
> 该教程演示用的是 **30×30×30 mm** 木块（机器码）。

**这几乎就是赛题的原型：巡线 → 识别目标 → 夹取 → 继续巡线。**

### ③ 色块颜色分拣 — `4.机械臂与三维空间夹取/6.色块颜色分拣/`
相关还有 `7.分拣高度异常色块`、`8.追踪夹取色块`、`9.木块形状分拣`、`3.机器码ID分拣`。

### ④ 四色识别源码 — `M3Pro_demo/color_recognize.py` ⭐⭐

```python
self.red_hsv_text    = os.path.join(package_pwd, 'red_colorHSV.text')
self.green_hsv_text  = ...  'green_colorHSV.text'
self.blue_hsv_text   = ...  'blue_colorHSV.text'
self.yellow_hsv_text = ...  'yellow_colorHSV.text'
```

> **官方颜色识别直接内置 红 / 绿 / 蓝 / 黄 四色 —— 与赛题方块颜色完全一致。**
> 且支持 `write_HSV()` **现场重新标定并写回**，配合 `Roi_hsv()` 框选取色工具。
> → 现场光照变化时可以重新标定，这个能力很关键。

### ⑤ 巡线源码 — `M3Pro_demo/follow_line.py` + `follow_common.py`

`follow_line.py` 中 `LineDetect` 节点的接口（实测读源码）：

| 方向 | 话题 / 类型 | 作用 |
|---|---|---|
| 订阅 | `/scan1` `LaserScan` | 雷达避障 |
| 订阅 | `/JoyState` `Bool` | 手柄状态 |
| 订阅 | `grasp_done` `Bool` | 抓取完成回执 |
| 发布 | `/cmd_vel` `Twist` | 底盘速度 |
| 发布 | `/beep` `UInt16` | 蜂鸣器报警 |
| 发布 | `arm6_joints` `ArmJoints` | 机械臂关节 |
| 发布 | `PosInfo` `AprilTagInfo` | 目标位置信息 |

方法：`remove_obstacle(point_x, point_y)` —— 清障动作。

`follow_common.py` 中 `line_follow(rgb_img, hsv_msg)` 的算法：
```
BGR → cvtColor(HSV) → inRange(lower, upper) → mask
    → 灰度 → threshold(10, 255, BINARY) → 求线中心 → PID 控制
```
另有 `Roi_hsv()` 交互式 HSV 取色、`PID` 类（P/I/D）。

默认巡线 HSV 参数文件 `LineFollowHSV.text` 内容：
```
34, 98, 74, 125, 253, 255      # 下界(H,S,V) + 上界(H,S,V)
```
> ⚠️ 这是官方示例值。**赛题是黑色电工胶布，必须现场用 `Roi_hsv()` 重新标定。**

## 4. 官方没给、必须自己写的部分

| 缺口 | 说明 |
|---|---|
| **迷宫在线探索与决策** | 官方路网（`RoadNetwork`）是**离线人工标注**路点的；赛题要求现场未知迷宫 → 需要在线建拓扑树 + DFS/策略 |
| **多目标收集与携带** | 官方是"夹一个放一边"；赛题要**带 8 个方块到出口** → 需要携带结构或多次往返策略 |
| **收益/罚时权衡** | 罚时规则现场公布，官方无此逻辑 |
| **完整比赛状态机** | 入口→探索→收集→出口→兜底，需要自己串 |
| **死路/路口的拓扑判定** | 官方巡线只沿线走，不判 T/十字/死路 |
