## 5. 路网规划导航（6 文档）—— 概念参考，流程不适用

核心：Nav2 **route server** + `.geojson` 路网描述（节点+边）+ slam_toolbox 先建栅格图 + 位姿地图 +
route_tool 标注 + cyclonedds DDS 切换 + 路点间导航（route_bridge.py / conver_speed.py）。

> ⚠️ 与赛题冲突点：路网是**离线建图+人工标注**的，赛题迷宫现场公布 → 不能直接用。
> 可借鉴：route_server 的"沿预定义路径导航"思路（与我们的 MazeMap frontier 同构）、
> conver_speed.py 的速度平滑做法。
